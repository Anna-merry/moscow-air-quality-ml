# Moscow Air Quality & Traffic Emission Forecasting

Модель машинного обучения для краткосрочного прогнозирования концентрации мелкодисперсных частиц PM2.5 и расчета индекса качества воздуха (US EPA AQI) в Москве с учетом транспортных пиков и метеоусловий.

## О проекте
Загрязнение частицами PM2.5 в мегаполисе напрямую зависит от автомобильного трафика и условий рассеивания (скорость ветра, инверсии температур).  
В проекте реализован полный цикл: от выгрузки данных через API до обучения ансамблевых моделей и интерактивной визуализации районов.

## Данные и пайплайн
* **Источники:** Open-Meteo API (Historical Weather & Air Quality).
* **Объем выборки:** 18 200+ почасовых записей (2023–2026 гг.) по ключевым загрязнителям (PM2.5, PM10, NO₂, CO, SO₂, O₃) и метеопараметрам.
* **Feature Engineering:**
  * Циклическое кодирование времени (`hour_sin`, `hour_cos`, `month_sin`, `month_cos`);
  * Прокси-признаки часов пик (`rush_morning`, `rush_evening`, `peak_traffic`);
  * Комбинированный признак штиля в час пик (`rush_low_wind`);
  * Временное разбиение 80/20 без перемешивания (исключение data leakage).

## Сравнение моделей

| Модель | Test R² | MAE (мкг/м³) | Разрыв Train/Test (Overfitting) |
|---|---|---|---|
| **Random Forest (n=100, depth=15)** | **0.978** | **2.11** | **0.018 (минимальный)** |
| **Gradient Boosting (n=100, depth=5)** | **0.975** | **2.24** | **0.021** |
| **Ridge Regression (alpha=10.0)** | **0.967** | **2.58** | **0.002** |
| *KNN Regressor* | *0.844* | *—* | *0.156 (отклонен из-за переобучения)* |

## Ключевые инсайты 
1. **PM10 и NO₂/CO** — главные предикторы, подтверждающие доминирование транспортного следа в загрязнении.
2. **Скорость ветра** — обратная зависимость: при штиле (<2 м/с) в часы пик фиксируются максимальные скопления частиц.
3. **Суточный профиль** — выраженная двухвершинная волна (8:00 и 18:00 в будни), сглаживающаяся в выходные.

## Геопространственный анализ
Сгенерирована интерактивная тепловая карта `moscow_smart_aqi.html` на базе **Folium/Leaflet**, визуализирующая расчетный градиент AQI и дифференциацию районов по типам загрязнения (Тверской — транспортный след, Марьино — смешанный промышленно-транспортный).
